# AsuX

Prototype game 2D sandbox terinspirasi game world-building berbasis blok, dibuat dengan Godot 4.

## Fitur awal
- Satu world 2D.
- Karakter bisa bergerak kiri/kanan, melompat, dan memukul.
- Inventori berisi Tanah, Batu, Air, dan Pasir (masing-masing 20).
- Pukul blok di dekat karakter untuk mengambilnya.
- Pilih blok lalu sentuh area kosong untuk memasangnya.
- Kontrol keyboard dan tombol layar sentuh.

Buka `project.godot` menggunakan Godot 4.x.
